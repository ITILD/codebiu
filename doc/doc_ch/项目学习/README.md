## 快速上手演示(Slidev PPT)

新成员入门 PPT，10 分钟了解全貌：

```bash
cd doc/doc_ch/ppt
pnpm i
pnpm run dev   # http://localhost:50004
```

详见 [ppt/README.md](./ppt/README.md)。
