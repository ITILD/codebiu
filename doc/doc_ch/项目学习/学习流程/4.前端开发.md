# 前端开发指南

> 前端基线库：`code/frontend/vue3`，技术栈 **Vue3 + TypeScript + Vite + Element Plus + UnoCSS + Pinia**。
> 整体界面为**淡绿色自然笔记风格**，顶栏 + 左侧模块菜单布局(RuoYi 式)。

## 1. 启动

```bash
cd code/frontend/vue3

pnpm i         # 安装依赖
pnpm run dev   # 开发模式(代理后端 base_server)
pnpm run build # 生产构建(含 type-check)
```

## 3. 布局约定

```
┌──────────────────────────────────────────┐
│ SysHeader(顶栏: Logo/主题/头像)          │
├─────────┬────────────────────────────────┤
│         │                                │
│ SysSidebar│      RouterView(页面内容)    │
│ 模块菜单  │                                │
│         │                                │
└─────────┴────────────────────────────────┘
```

- 布局在 `App.vue` 全局渲染，**新页面只写内容区**，不要自己包 Header/Sidebar
- 模块菜单在 `SysSidebar.vue` 的 `menuItems` 中维护
- 登录认证与账户设置入口在顶栏头像下拉(`UserControl.vue`)

## 4. 新页面开发三件套

以"示例管理"页面为例：

### ① 类型 `types/demo.ts`

```ts
/** 示例条目(与后端 DO 对应) */
type Demo = {
  id: string
  name: string
  is_active: boolean
  created_at: string
}
```

### ② 接口 `api/demo/index.ts`

```ts
import { http_base_server } from '@/utils/http'

/** 查询示例列表 */
export const listDemo = () => {
  return http_base_server.get<Demo[]>('/demo/demo/list')
}
```

> `utils/http.ts` 已对响应做**自动解包**，直接拿到数据体。
> 文件下载等非 JSON 场景用 `getFileDownloadUrl` 拼相对路径新窗口打开。

### ③ 页面 `pages/_sys/demo/index.vue`

- **文件路径即路由**：`pages/_sys/demo/index.vue` → `/_sys/demo`
- **组件优先用 Element Plus**：表格 `el-table`、表单 `el-form`、
  弹窗 `el-dialog`、消息 `ElMessage`、确认框 `ElMessageBox`、
  目录树 `el-tree`(懒加载)、上传 `el-upload`
- 样式用 UnoCSS 原子类，主题快捷类见下表

页面骨架示例：

```vue
<template>
  <div p-2 w-full flex flex-col h-full>
    <!-- 工具栏 -->
    <div mb-3 flex items-center gap-2> ... </div>

    <!-- 数据表格 -->
    <el-table v-loading="loading" :data="items" border stripe flex-1> ... </el-table>

    <!-- 分页 -->
    <el-pagination v-model:current-page="page" :total="total" />
  </div>
</template>
```

## 5. 主题与样式规范

主题变量定义于 `assets/base.css`，UnoCSS 快捷类定义于 `uno.config.ts`：

| 快捷类 | 用途 |
| :--- | :--- |
| `bg-note-paper` | 页面纸张底色(米白/暗色深绿黑) |
| `bg-note-soft` | 柔和淡绿底(顶栏/侧栏) |
| `bg-note-card` | 卡片白 |
| `bg-note-tint` | 淡绿强调底(悬浮态) |
| `text-note` / `text-note-sub` | 主文字 / 次级文字 |
| `text-note-green` | 苔绿强调色 |
| `border-note` | 淡绿灰边框 |
| `shadow-note` | 柔和纸片阴影 |
| `bg-note-gradient` | 苔绿渐变(hero 区) |

规则：

- 全部快捷类已适配**暗色模式**，禁止写死十六进制色值
- Element Plus 主色已被主题变量覆盖，直接用默认 `type="primary"` 即可
- 新增全局色值时先在 `base.css` 建变量，再到 `uno.config.ts` 加快捷类

## 6. 状态管理

| Store | 职责 | 常用字段 |
| :--- | :--- | :--- |
| `auth.ts` | 登录态 | `authState.user` / `token` / `avatar` |
| `sys.ts` | 界面态 | `sysStyle.theme.isDark` / `isMd` / `isSidebarDrawerOpen` |
| `router.ts` | 路由态 | `routerPath.now`(侧栏激活项) |

## 7. 与后端联调

- 开发代理配置：`tools/vite/proxy.ts` + `.env.development`
- 后端接口前缀：`/base_server/<module>/...`，axios 实例已处理
- 字段命名保持**后端蛇形**(snake_case)原样透传，不在前端二次映射
- 分页响应统一结构：`{ items, total, page, size, pages }`
