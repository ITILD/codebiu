# 06-版本开发

自项目设立（2025-11）起的逐版本开发记录。版本 cadence 规则：

1. **每月至少一个版本**：自项目设立起，有开发活动的月份至少归档一个版本（2026-06 为沉淀期，无提交，不设版本）。
2. **大功能设中间小版本**：当月如有大的功能改动（如动态配置中心），增补中间小版本。
3. **最短间隔一周**：相邻两个版本的发布日期间隔不少于一周。
