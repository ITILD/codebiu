# v1.2.0 智能扩展版

> 开发周期：2026-09-01 ~ 2026-09-08
> 上一版本：[v1.1.0](./v1.1.0.md) ｜ 下一版本：[v1.3.0](./v1.3.0.md)

## 版本功能

- **权限体系完善**：多模块功能迭代与权限完善；权限设置页面 UI 与文案优化
- **认证升级**：OAuth2 标准登录端点（支持 Swagger Authorize）
- **网页搜索模块**：重构搜索引擎目录结构，新增 Tavily 与 Firecrawl 引擎
- **LLM 数据清洗模块**：独立数据清洗模块，复用 AI 模块的 LLM 服务；文档分块策略优化
- **模型分部门管理**：AI 模型按用户/部门管理（public / dept / user 三类 scope）
- **三维地理可视化模块**：新增 GIS 模块，完善认证与监控功能
- **个人小站模块**：整合原小工具与博客模块
- **智能体模块**：新增 agent 模块，完善页面布局与交互
- **RAG 优化**：知识库模块页面结构重构（内嵌管理面板）、重排（rerank）代码重构与向量库流程优化
- **基础设施**：rich 库日志实现、启动钩子机制重构（拆分初始化流程）、前台路由与导航体系重构
