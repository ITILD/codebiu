# v0.3.0 文件存储重构版

> 开发周期：2026-01-01 ~ 2026-01-31
> 上一版本：[v0.2.0](./v0.2.0.md) ｜ 下一版本：[v0.4.0](./v0.4.0.md)

## 版本功能

- **文件存储重构**：多存储系统支持（本地 / S3 对象存储）、预签名 URL 上传下载、MD5 → content_hash 多哈希支持
- **AI 模块启用**：AI 模块正式启用 + 模型配置示例 + LLM 请求基础模板项目
- **字典管理**：新增字典类型与字典项模块
- **系统监控**：系统状态监控页面、Monaco 代码编辑器接入、uistore 页面增强
- **认证体系重构**：user store → auth store、token expires_at 时区支持、登录注册流程优化、用户控制组件下拉菜单化
- **基础设施**：DBEX 重命名为 DBConfigFactory、数据库连接池异步配置修复、日志轮转与处理器优化
- **工程化**：docker-compose 脚本、极简全栈 Web 服务模板、Slidev 演示项目、前端 `_server` → `_sys` 结构调整
