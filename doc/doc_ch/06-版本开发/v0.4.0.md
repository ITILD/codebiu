# v0.4.0 文件系统完善版

> 开发周期：2026-02-01 ~ 2026-02-28
> 上一版本：[v0.3.0](./v0.3.0.md) ｜ 下一版本：[v0.5.0](./v0.5.0.md)
> 本月聚焦文件系统收尾：去重、引用计数与测试基建。

## 版本功能

- **文件内容去重**：基于 content_hash 的文件内容去重，相同内容只存一份
- **引用计数**：文件条目引用计数机制，预签名上传成功后处理逻辑打通
- **模块拆分**：文件系统模块拆分为文件内容与文件条目两条管理线，API 设计优化
- **对象存储**：对象存储接口代码与错误提示优化、上传配置与响应结构重构
- **测试基建**：测试改用 AsyncClient 替代 TestClient，文件名参数化测试
