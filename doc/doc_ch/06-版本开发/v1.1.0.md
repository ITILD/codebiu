- **LLM 工具链重构**：重构 AI 模型加载工具链，迁移并整理原有代码，形成统一加载入口
- **模型增强**：Qwen 推理内容（reasoning content）提取支持；新增 huggingface-hub 依赖与模型下载脚本
- **容器化与运维**：deveops 运维脚本（docker 开发部署）、前端 docker 构建配置、后端 dev dockerfile 更新
- **资源扩充**：批量新增项目资源、模块与配置文件
