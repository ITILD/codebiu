# v0.5.0 流式聊天版

> 开发周期：2026-03-01 ~ 2026-03-31
> 上一版本：[v0.4.0](./v0.4.0.md) ｜ 下一版本：[v0.6.0](./v0.6.0.md)

## 版本功能

- **SSE 流式响应**：LLM 支持 SSE 事件流式响应，重构模型类型定义与消息流处理
- **流式聊天**：聊天页面实现流式输出（reactive 包装助手消息实时渲染）、chat 模型列表、UI 交互优化
- **同义词管理**：新增 NLP 同义词模块，批量分组查询与批量更新
- **图数据库迁移**：kuzu → ladybug 引擎迁移
- **Nuitka 工具链**：模块化编译工具与配置、模块构建脚本
- **路由启用**：授权、模板、AI 模块路由控制器正式启用，菜单顺序与 vite 配置优化
- **模板扩展**：Python 项目模板初始化、图像处理功能
