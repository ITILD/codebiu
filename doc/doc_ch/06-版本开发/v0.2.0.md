# v0.2.0 多数据库版

> 开发周期：2025-12-01 ~ 2025-12-31
> 上一版本：[v0.1.0](./v0.1.0.md) ｜ 下一版本：[v0.3.0](./v0.3.0.md)

## 版本功能

- **向量数据库**：Milvus Lite 替换为 LanceDB，重构向量库实现并抽象基类，统一数据库接口命名
- **图数据库**：新增 Neo4j 支持与单步关联查询；本地图引擎 kuzu → graph_local 演进，networkx 增强
- **关系数据库**：多数据库配置落地，重构数据库连接管理（pymilvus 依赖引入）
- **文件系统初版**：文件系统模块重构，数据库连接与文件操作打通
- **AI 模型接入**：Ollama 本地模型支持、AWS 模型接入、模型配置校验与格式化检查增强
- **任务队列**：引入 Celery 依赖与 Redis 配置
- **运维脚本**：服务器初始化脚本（uv / docker 一键安装）
- **前端**：React 项目基础架构与功能模块补充
