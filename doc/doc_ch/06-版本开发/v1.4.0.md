# v1.4.0 动态配置中心版（开发中）

> 开发周期：2026-09-18 ~ 至今
> 上一版本：[v1.3.0](./v1.3.0.md)
> 当前 dev 分支正在进行的版本。动态配置中心属于大的功能改动，按版本规则设立中间小版本；发布后归档。

## 版本功能（已完成部分）

- **可拖动悬浮工具**：新增可拖动悬浮工具组件与独立下载权限体系
- **动态配置中心核心**：`common/runtime.py` 运行时注册表（启动期显式装配、运行期调用时解析），`common/config/db.py` 重构为"恒定门面代理 + 显式装配"（`init_runtime`），存量 `@DaoRel` 等用法零改动支持配置热刷新
- **动态配置落地**：sys_config 表（JSON 列）+ Pydantic 分组 schema + TTL 缓存 + 首启 yaml 种子迁移；token / email / websearch / file_system / db_cache / db_vector / db_graph / tasks / admin 九组配置动态化
- **配置中心 API 与页面**：新增 `/sys-configs` 配置中心 API 与 `main:config` 权限；系统管理-通用配置页（元数据驱动表单、密钥打码、连接级配置"重启生效"标注）
- **工程治理**：config.dev.yaml 标注动态配置迁移节与保留节，启动注释与前端类型约束补全
