# v0.1.0 基线初始化版

> 开发周期：2025-11-14 ~ 2025-11-30
> 上一阶段：[0.x 初始开发综述](../05-初始开发/0.x-基线搭建.md) ｜ 下一版本：[v0.2.0](./v0.2.0.md)
> 项目起点：前后端基线从零初始化，跑通第一个月的开发闭环。

## 版本功能

- **后端基线**：FastAPI + uv 项目结构初始化，controller/service 分层与统一返回
- **前端基线**：Vue3 项目框架、React 前端基础架构双线起步
- **认证雏形**：登录注册流程初步接入
- **业务模块探索**：OCR 前后端、Excel 读写处理、CAD 能力、常用图标
- **模板与工具**：用户与模板模块重构、基于 string.Template 的模板管理、pip 库 / `uv add` 库模板
- **工程化**：打包方案验证（候选打包配置、Nuitka 加密编译）、docker 构建脚本重构
- **依赖探索**：deepagents 文件系统后端依赖试验
