# v1.3.0 任务引擎与体验统一版

> 开发周期：2026-09-09 ~ 2026-09-17
> 上一版本：[v1.2.0](./v1.2.0.md) ｜ 下一版本：[v1.4.0](./v1.4.0.md)

## 版本功能

- **双引擎任务调度**：新增本地任务执行引擎，与 Celery 形成双引擎调度（`app_task.py`）
- **大模型工具链全量重构**：`module_ai` 清理旧代码，新增 OCR、LLM 工具链与重排功能；模型自动检测、模型缓存与 rerank 支持
- **模型设置面板重构**：新增语音模型支持；会话标题自动生成
- **个人小站重构**：site 模块路由与页面结构重构
- **体验统一**：统一 UI 风格（移除冗余边框）、聊天界面布局与文案优化、菜单与权限名称更新
- **工程治理**：统一包管理器为 pnpm、前端端口配置调整、进程杀死工具完善、公共资源路径收敛到 app 目录与组合式函数沉淀
