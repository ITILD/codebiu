# v1.0.0 基线稳定版

> 开发周期：2026-07-01 ~ 2026-07-31
> 上一阶段：[0.x 初始开发](../05-初始开发/0.x-基线搭建.md) ｜ 下一版本：[v1.1.0](./v1.1.0.md)
> 本版本起项目进入稳定期，按版本规划开发与发布。

## 版本功能

- **RAG 知识库模块**：新增知识库管理、文档解析与检索问答链路（`module_rag` 雏形）
- **权限系统重构**：Casbin RBAC 接入，域分离模型（`rbac_model.conf`），按模块声明权限
- **语音模块**：完整的 ASR / TTS 语音识别与合成功能（`module_ai` 语音部分）
- **工程治理**：标准 Enum 全面替换为 StrEnum、批量清理冗余代码、全局 app name / version 配置、语音与 AI 模块依赖升级
