# 响应式自适应规范

> 适用范围：`code/frontend/vue3`（Vue3 + Element Plus + UnoCSS）。
> 目标：同一套代码在手机（竖屏/横屏）、平板、桌面、超宽屏上都有合理的布局与可读性，避免出现横向滚动、文字截断、按钮挤压、点击热区过小等问题。
> 本规范与 `uno.config.ts`、`base.css` 中的既有约定（`--note-*` 变量、`h-app`、`page-shell`、`note-sm/md/lg` 圆角）保持一致，新增样式必须复用这些约定，不得另起炉灶。

---

## 1. 断点体系

### 1.1 统一断点

以 UnoCSS `presetWind3`（Tailwind v3 语义）为准，全站只使用以下断点，**禁止自定义额外断点值**：

| 代号 | 最小宽度 | 典型设备 | 布局定位 |
|------|----------|----------|----------|
| （默认） | 0px | 手机竖屏（<768px） | 单列、抽屉导航、大间距 |
| `sm` | 640px | 手机横屏 / 小平板竖屏 | 单列为主，允许双列卡片 |
| `md` | 768px | 平板竖屏 / 小窗口桌面 | 侧边导航出现，双列布局 |
| `lg` | 1024px | 平板横屏 / 笔记本 | 标准桌面布局 |
| `xl` | 1280px | 桌面 | 内容区限宽 |
| `2xl` | 1536px | 大屏 / 超宽屏 | 内容区限宽居中 |

### 1.2 断点使用原则

- **移动优先**：样式先写手机端，再用 `sm:` `md:` `lg:` 向上覆盖。例如既有 shortcut：

  ```html
  <!-- page-shell: 移动 p-4, 桌面 p-6 -->
  <main class="page-shell">...</main>
  <!-- h-app: 移动减去 h-14 导航, 桌面减去 h-16 -->
  <section class="h-app">...</section>
  ```

- **只升不降**：不使用 `max-md:` 之类的反向断点做主逻辑（个别微调除外），保证样式推导方向一致。
- **跳档合并**：从手机直接跳桌面用 `md:` 即可，不要写出 `sm:md:lg:` 三连重复覆盖。
- **关键分界线**：`md`（768px）是"手机/桌面"的分界，导航形态、列数、弹窗形态在此切换；`lg`（1024px）是"内容限宽"分界。

## 2. 字体规范

### 2.1 字号阶梯

全站字号使用 `rem`，根字号不锁定（跟随系统/浏览器设置）。禁止使用 `px` 写正文字号，图标与 1px 细节除外。

| 层级 | 手机（<md） | 桌面（≥md） | UnoCSS 写法 | 用途 |
|------|------------|------------|-------------|------|
| Hero 标语 | 28px | 36px | `text-3xl md:text-4xl` | 首页主标语 |
| 页面标题 H1 | 22px | 24px | `text-xl md:text-2xl` | 页面头 |
| 区块标题 H2 | 18px | 20px | `text-lg md:text-xl` | 卡片/面板标题 |
| 小标题 H3 | 16px | 16px | `text-base font-semibold` | 表单分组、列表头 |
| 正文 | 14px | 14px | `text-sm` | 默认正文（与 Element Plus 对齐） |
| 辅助说明 | 12px | 12px | `text-xs text-note-sub` | 提示、占位、时间戳 |
| 手写体点缀 | 按需 | 按需 | `font-hand` | Hero/空状态装饰，不承载信息 |

### 2.2 行高与字重

- 正文行高统一 `leading-relaxed`（1.625）；标题用默认 1.3 左右，不额外设置。
- 中文字重只用三档：`font-normal`（正文）、`font-medium`（强调）、`font-semibold`（标题）。**禁止 `font-bold` 用于中文长文本**（笔画糊）。
- 数字/代码用 `font-mono`；金额、ID 等需要对比的数值列也用 `font-mono` + `text-right`。

### 2.3 文本自适应与截断

- **单行截断**：一律用既有 rule `text-ellipsis`，不手写三条属性。

  ```html
  <span class="text-ellipsis">很长的文件名.docx</span>
  ```

- **多行截断**：`line-clamp-2` / `line-clamp-3`（presetWind3 内置）。
- **标题不截断**：页面 H1 允许换行，禁止对标题截断导致语义丢失。
- **最小可读字号**：任何文本不小于 12px；`text-xs` 只用于辅助信息，不可用于主操作按钮文字。
- **长词/URL 兜底**：展示用户输入、URL、hash 的容器加 `break-all` 或 `break-words`，防止撑破容器。

## 3. 按钮规范

### 3.1 尺寸分档

Element Plus 按钮在三档尺寸间随断点切换，**通过 `size` 属性 + 动态计算实现，不用 CSS 覆盖改写按钮内部 padding**：

```ts
// composables/useResponsive.ts（约定：全局唯一获取断点的入口）
import { useBreakpoints } from '@vueuse/core'

const breakpoints = useBreakpoints({ sm: 640, md: 768, lg: 1024, xl: 1280 })
/** 是否移动端布局（<768px），全站共用 */
export const isMobile = breakpoints.smaller('md')
```

```vue
<el-button :size="isMobile ? 'large' : 'default'">保存</el-button>
```

| 场景 | 手机 | 平板/桌面 | 说明 |
|------|------|-----------|------|
| 页面主操作（提交/保存） | `large`（≥40px 高） | `default`（32px） | 主操作在移动端加大，保证触控 |
| 表格行内操作 | `small` | `small` | 两侧不随断点变化 |
| 工具栏图标按钮 | 自定义 `note-icon-btn` | 同左 | 28px 方寸，见 `uno.config.ts` |
| 表单内按钮 | 与表单控件同高 | 同左 | 跟随 el-form 尺寸 |

### 3.2 布局与排列

- **主按钮唯一**：一个视图内 primary 色按钮最多 1 个，其余用 default / text。
- **移动端按钮排布**：
  - 操作数 ≤2：底部通栏，主按钮在右；

    ```html
    <div class="fixed bottom-0 inset-x-0 p-4 flex gap-3 bg-note-card md:static md:p-0">
      <el-button class="flex-1" plain>取消</el-button>
      <el-button class="flex-1" type="primary">保存</el-button>
    </div>
    ```

  - 操作数 >2：收进"更多"下拉（`el-dropdown`），移动端只保留主操作 + 更多。
- **按钮组间距**：横向 `gap-2`（8px）起，禁止用 margin 拼间距；两端对齐用 `mini-text-center-between`。
- **按钮文字**：中文 2~4 字，不换行（按钮加 `whitespace-nowrap`）；移动端禁止图标+长文混排溢出。
- **加载/禁用态**：异步提交必须 `:loading`，防止移动端重复点击；禁用态不加自定义遮罩。

### 3.3 触控热区

- 所有可点元素热区 ≥ **44×44px**（含 padding），小于该值的图标按钮必须扩大热区：

  ```html
  <!-- 28px 图标按钮外扩热区 -->
  <button class="relative after:absolute after:-inset-2 after:content-['']">…</button>
  ```

- 相邻可点元素间距 ≥ 8px，防止误触。

## 4. 边框规范

### 4.1 基本原则

- 边框颜色一律取主题变量：`border-note`（淡绿灰）或 `border-note-green`（强调），**禁止写死 hex**。
- 边框宽度只用 1px；强调/选中态可用 2px，但需要预留空间防止布局抖动（选中态优先用底色 `bg-note-tint` 表达，而不是加粗边框）。
- 分隔线：卡片内用虚线 `note-dashed-divider`，列表项之间用 `divide-y divide-note/60`。

### 4.2 无边框优先

延续现有视觉约定：**用色差和阴影区分层级，而不是画边线**。

| 层级 | 手机/桌面统一做法 |
|------|-------------------|
| 卡片 | `page-card`（无边线纸片 + `shadow-note` 光晕环） |
| 输入框/按钮 | 保留 Element Plus 默认 1px，不改写 |
| 分区 | 背景色差（`bg-note-soft` vs `bg-note-paper`），不画框 |
| 表格 | 去竖线：`<el-table>` 不开 `border`，仅保留行分隔 |

- 边框圆角必须用语义刻度：`rounded-note-sm`（输入框/按钮）、`rounded-note-md`（卡片/表格）、`rounded-note-lg`（对话框/抽屉），禁止任意 `rounded-[13px]`。

### 4.3 响应式边框处理

- 移动端卡片默认无边框，靠阴影分层；桌面如需描边统一 `md:border md:border-note/60`，且加边框的同时不得再叠加阴影变化，避免二选一。
- 全宽场景（移动端卡片贴边）用 `-mx-4` 负边距吃掉 `page-shell` 内边距时，**必须同时去掉圆角**：`-mx-4 rounded-none md:mx-0 md:rounded-note-md`。

## 5. 按钮组与操作区显示优化

### 5.1 工具栏（card-toolbar）

沿用既有 shortcut `card-toolbar`（`flex flex-wrap items-center justify-between gap-2`），左侧标题、右侧操作：

```html
<div class="card-toolbar">
  <h2 class="text-lg md:text-xl font-semibold">项目列表</h2>
  <div class="flex flex-wrap items-center gap-2">
    <el-input class="w-full sm:w-52" placeholder="搜索…" />
    <el-button type="primary">新建</el-button>
  </div>
</div>
```

- 移动端搜索框 `w-full` 独占一行，桌面 `sm:w-52` 收窄；靠 `flex-wrap` 自动换行，不写 media query。
- 工具栏操作超过 3 个时，低优先级操作收进 `el-dropdown`（"更多"），不堆按钮。

### 5.2 表格行内操作

- 行内操作 >2 个：移动端只显示 1 个主操作，其余进 `el-dropdown`；桌面显示全部（≤3 个）。
- 行内按钮一律 `text` 型 + `small`，用图标 `i-ep-xxx` + tooltip，不占宽度：

  ```html
  <el-button link size="small" @click="edit(row)"><i class="i-ep-edit" /></el-button>
  ```

### 5.3 表单按钮组

- 弹窗表单：按钮放 footer 右对齐 `justify-end gap-2`；移动端弹窗转全屏（见 §7.3）后按钮底部固定。
- 筛选表单：`el-form` 用 `inline` 模式 + `flex-wrap`，移动端每项 `w-full sm:w-auto`。

### 5.4 分页与批量操作

- 分页：移动端只显示 `prev / pager(5) / next`（`layout="prev, pager, next"`），桌面完整 `layout="total, sizes, prev, pager, next, jumper"`，通过 `:layout="isMobile ? ... : ..."` 切换。
- 批量操作栏：选中后浮现（表格上方 `card-toolbar` 内），移动端操作过多时收进下拉。

## 6. 布局组件自适应

### 6.1 栅格与列数

用 UnoCSS Grid，列数随断点递增，间距统一 `gap-4`（16px）：

| 内容类型 | 手机 | sm | md | lg+ |
|----------|------|----|----|-----|
| 卡片列表 | 1 列 | 2 列 | 2~3 列 | 3~4 列 |
| 表单 | 1 列 | 1 列 | 2 列 | 2~3 列 |
| 统计指标 | 1 列 | 2 列 | 3 列 | 4 列 |

```html
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-4">
  <ProjectCard v-for="p in list" :key="p.id" />
</div>
```

### 6.2 导航

- **手机（<md）**：顶部 `h-14` 吸顶导航（`bg-note-glass + backdrop-blur-md`），侧边内容收进抽屉 `el-drawer`。
- **桌面（≥md）**：顶部 `h-16` + 常驻侧边栏（宽度 `w-56 lg:w-64`）。
- 内容区高度统一用既有 `h-app` / `max-h-app`，禁止各页面自己算 `calc`。

### 6.3 弹层

| 组件 | 手机 | 桌面 |
|------|------|------|
| Dialog | 全屏或 `width="92%"`，`top` 减小 | 居中，宽度按内容 480~720px |
| Drawer | 底部抽屉（`direction="btt"`）适合列表选择；表单编辑用全屏 | 右侧抽屉 `size="480px"` |
| Popover/Dropdown | 允许时转 `el-drawer` 或全屏 ActionSheet | 默认 |

```html
<el-dialog
  :width="isMobile ? '92%' : '640px'"
  :fullscreen="false"
  :close-on-click-modal="!isMobile"
/>
```

- 弹窗内滚动：内容区 `max-h-app overflow-auto`，footer 不随内容滚动。
- 移动端禁用 `close-on-click-modal`（误触率高）。

### 6.4 表格

- 有横向滚动的表格：外层容器 `overflow-auto`，`el-table` 固定首列（`fixed="left"`）+ 至少一列 `fixed="right"`（操作列）。
- **移动端优先方案**：复杂表格在 <md 降级为卡片列表（每行一张卡，字段用 label:value 排布），用 `isMobile` v-if 切换，两套结构共用同一数据源。
- 列宽：给可能很长的列设置 `min-width` 而不是 `width`，让表格自己分配。

### 6.5 表单

- Label 位置：桌面 `label-position="right"` + `label-width`；移动端 `label-position="top"`：

  ```vue
  <el-form :label-position="isMobile ? 'top' : 'right'" :label-width="isMobile ? undefined : '96px'">
  ```

- 输入控件宽度：移动端 `w-full`；日期范围、级联等宽控件在移动端单独换行。
- 校验信息不挤压布局：Element Plus 默认行为即可，禁止自定义绝对定位的错误提示。

## 7. 系统与设备适配

### 7.1 安全区（刘海屏/底部手势条）

```css
/* base.css 或页面根容器 */
.page-shell { padding-bottom: calc(1rem + env(safe-area-inset-bottom)); }
/* 底部固定按钮栏 */
.bottom-bar { padding-bottom: calc(1rem + env(safe-area-inset-bottom)); }
```

- `viewport` meta 须包含 `viewport-fit=cover`（检查 `index.html`）。

### 7.2 输入与交互

- 表单输入 `font-size ≥ 16px` 时可阻止 iOS 聚焦自动放大：移动端弹窗/表单内输入框用 `size="large"`（40px 高，字号 16px）。
- 禁用移动端双击缩放带来的点击延迟：现代浏览器已消除 300ms 延迟，无需 fastclick。
- 拖拽类交互（VueFlow、画板）在触屏上必须提供替代操作（长按菜单或按钮），并在 <md 时提示"建议使用桌面端获得完整体验"。

### 7.3 横竖屏与键盘

- 手机横屏（`sm` 档）：允许 2 列，但视频/画布类保持全宽。
- 软键盘弹起：表单页用 `min-h` 而非 `h` 定高，避免键盘顶飞布局；底部固定按钮在键盘弹起时可隐藏（`focusin/focusout` 监听）。

### 7.4 超宽屏与限宽

- 内容主区限宽：`max-w-7xl mx-auto`（1280px），超宽屏两侧留白，不无限拉伸。
- 全局背景（`bg-note-paper`）铺满，内容卡片限宽居中。

---

## 8. 图片与媒体

- 图片容器固定宽高比：`aspect-video` / `aspect-square` + `object-cover`，防止加载抖动（CLS）。
- 头像用 `el-avatar` 固定尺寸，移动端缩小一档（`size` 随 `isMobile`）。
- 大图列表必须懒加载：`loading="lazy"`。
- 图标统一走 `presetIcons`（`i-ep-*`），尺寸用 `text-base/text-lg` 控制随字号缩放。

---

## 9. 性能与降级

- 动效统一走既有 `note-transition`（200ms ease-out）；移动端禁用大面积 blur（`backdrop-blur` 仅用于吸顶导航）、禁用 hover 抬升依赖（`note-card-hover` 在触屏无效但无害，不加 JS 判断）。
- 遵循 `prefers-reduced-motion`：

  ```css
  @media (prefers-reduced-motion: reduce) {
    *, *::before, *::after { transition-duration: 0.01ms !important; animation-duration: 0.01ms !important; }
  }
  ```

- 重型组件（Monaco、ECharts、VueFlow、Babylon）在 <md 时延迟加载或给出降级视图，不在首屏加载。

## 10. 自查清单（提测前过一遍）

- [ ] 375px（iPhone SE）：无横向滚动条、无文本溢出截断丢义
- [ ] 768px（md 分界）：导航、弹窗、表单 label 位置正确切换
- [ ] 1920px / 2560px：内容限宽居中，无拉伸变形
- [ ] 所有可点元素热区 ≥ 44×44px，间距 ≥ 8px
- [ ] 主操作按钮移动端 `large`、桌面 `default`；primary 唯一
- [ ] 表格移动端可横向滚动（首列+操作列固定）或已降级为卡片
- [ ] 弹窗移动端禁用点遮罩关闭；footer 按钮不随内容滚动
- [ ] 底部固定元素已加 `env(safe-area-inset-bottom)`
- [ ] 输入框聚焦不被系统键盘遮挡
- [ ] 字号未用 px 写死；无小于 12px 的文本
- [ ] 边框/圆角/颜色全部引用 `--note-*` 变量与语义刻度
- [ ] 触屏设备 hover 依赖的功能有替代入口
