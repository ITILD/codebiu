# 01 - 需求分析

> 适用范围：`code/backend/server_py`（FastAPI 后端，代号 base-server）与 `code/frontend/vue3`（Vue3 前端，代号 CODE_BIU）。
> 本文从业务视角梳理系统的功能需求与非功能需求；技术实现见 [02-总体架构与功能设计](./02-总体架构与功能设计.md)，权限体系见 [03-权限设计](./03-权限设计.md)。

---

## 1. 项目概述

CodeBiu 是一套 **AI 能力驱动的模块化全栈业务平台**，包含前后端分离的完整实现：

- **后端**：Python 3.13 + FastAPI，按业务域拆分为 20 余个模块（module_*），可独立挂载/裁剪；
- **前端**：Vue 3 + Vite，模块化页面与后端模块一一对应，自动路由 + 权限过滤。

平台以 **知识库（RAG）问答** 与 **智能体** 为核心 AI 场景，同时内建系统管理（用户/角色/权限/部门）、统一文件存储、异步任务队列、个人小站（博客/备忘/记账）等一系列通用能力，可整体作为业务底座，也可按需裁剪为单一产品。

### 1.1 核心价值

| 价值点 | 说明 |
|--------|------|
| AI 全家桶 | 模型配置管理 + 多供应商 LLM 接入 + SSE 流式对话 + RAG 问答 + 智能体 + 语音（ASR/TTS）+ OCR |
| 开箱即用的权限底座 | Casbin 域隔离 RBAC + 项目级成员档位，模块自治声明权限 |
| 多存储统一抽象 | 关系库（PostgreSQL/SQLite）、缓存（Redis/Fakeredis）、向量库（Milvus/LanceDB）、图库（Neo4j）可配置切换 |
| 文件服务内容寻址 | SHA-256 去重秒传、分片断点续传、local/rustfs/S3 无缝切换 |
| 异步任务中心 | Celery 任务创建/轮询/取消/重试，task_queue 表为状态事实来源 |

| 角色 | 来源 | 典型诉求 |
|------|------|----------|

## 3. 功能需求

以下需求按业务域组织，编号与后端模块对应。每条需求注明主要承载端（后端模块 / 前端模块）。

### FR-1 认证与账户（module_authorization / authorization 模块）

- 支持用户名 + 密码注册、登录、登出；注册/登录即返回双令牌与用户信息。
- 支持 access_token 自动续期（refresh_token 刷新），登出后令牌即时失效。
- 用户可自助维护昵称/邮箱/电话/头像，自助修改密码（校验旧密码）。
- 账户可被管理员禁用（is_active），禁用后登录与刷新令牌均被拒绝。

### FR-2 系统管理（module_authorization + module_main / admin 后台）

- **组织与权限**：用户 CRUD（分页/启停/重置密码/头像）、角色 CRUD 与角色-权限分配、部门树管理、权限（菜单）树查询、Casbin 策略规则管理。
- **字典**：字典类型/字典项 CRUD，支持无限滚动加载与按编码查询，供业务下拉选项使用。
- **系统监控**：服务器状态（缓存 60s）、系统信息、硬件状态、网络状态、挂载子应用列表。
- **数据库工具**（开发用）：一键建表 / 重置数据库。

### FR-3 知识库（module_rag / rag 模块）——核心需求

- **项目管理**：创建/修改/删除知识库项目，支持分类（个人/项目/公司）与私有/公开标记；为每个项目惰性创建虚拟目录 `/rag/<项目名>/`。
- **文档入库**：
  - 上传文档（与统一文件服务打通，支持直传/中转/分片/秒传）；
  - 自动解析（docling 引擎：pdf/docx/pptx/xlsx/md/csv 等）→ 智能切分（通用/表格策略，可由 LLM 推荐策略）→ 向量化入库；
  - 解析任务异步执行（Celery），支持进度追踪、失败重试、重新解析、重新向量化；
  - 分块可查看、可管理。
- **检索**：稠密向量（语义）+ 稀疏向量（BM25 关键词）混合检索，RRF 融合重排，可选 Rerank 精排与分数阈值过滤。
- **知识库问答（RAG Chat）**：
  - 多轮对话，关联一个或多个知识库项目；
  - LangGraph 流程：意图分析（提取检索关键词、判断是否需要知识库）→ 知识库检索 → LLM 生成；
  - SSE 流式输出，区分推理过程/意图分析/知识检索/正式回答等事件区块；
  - 会话列表与消息持久化，历史分页查询；支持"深度思考"（Rerank 精排）开关；
  - 自动生成会话标题与历史压缩总结。
- **成员协作**：按用户/按部门邀请成员，三档角色（reader/editor/admin）；部门授权沿部门树级联生效；公开项目对登录用户只读。
- **个人模型配置**：用户可绑定自己的对话/向量/重排等模型（支持共享标记），问答按用户加载其模型。

### FR-4 智能体（module_agent / agent 模块）

- 内置公共智能体（翻译专家/通用写作助手/代码助手，启动幂等种子写入，不可删除）。
- 用户可自建"简单智能体"（system_prompt 驱动），仅创建者与管理员可修改/删除。
- 智能体流式对话：复用知识库会话体系（LangGraph 单节点图 + Postgres checkpointer），SSE 事件协议与 RAG 一致。
- 我的智能体对话列表（按智能体过滤）。

### FR-5 AI 服务（module_ai / ai 模块）

- **模型配置管理**：模型配置 CRUD（server_type：openai/dashscope/vllm/ollama/aws-bedrock 等，自动补默认地址），用户私有配置 + 共享标记。
- **通用 LLM 对话**：SSE 流式对话端点；历史经 localStorage 本地保存。
- **语音**：ASR 文件识别、ASR 流式识别（WebSocket）、TTS 文件合成（WAV）、TTS 流式合成（PCM 边收边播）；支持 sherpa-onnx 与 Qwen 本地引擎。
- **OCR**（预留）：PaddleOCR 系 ONNX 模型（中/繁/日/英检测识别 + 版面分析），配置于 config.yaml。

### FR-6 数据清洗（module_data_clean / data-clean 模块）

- 输入任意 JSON/字符串数据 + 清洗提示词 + 可选 JSON Schema，由 LLM 输出结构化清洗结果。

### FR-7 文件管理（module_file / file 模块）

- 虚拟文件树（目录/文件条目），支持新建目录、重命名、移动（同步维护子树路径）、批量删除（软删 + 引用计数归零清理物理文件）。
- 上传：小文件直传（SHA-256 内容哈希去重秒传）、S3 预签名直传、服务端中转、分片上传四件套（init/parts/complete/取消）。
- 下载：S3 存储走 302 直链，本地存储流式返回。
- 存储后端 local/rustfs/S3 无缝切换（配置驱动），支持存储迁移。

### FR-8 个人小站（module_site / site 模块）

- **博客**：Markdown 文章与外链两类来源，草稿/发布状态，前台已发布视图与管理分页视图分离，数据按用户隔离。
- **备忘（Todolist）**：树形任务，支持日历年/月/周视图数据源。
- **记账（Ledger）**：收入/支出记录，统计概览（分类饼图 + 月度趋势，支持月/年维度）。

### FR-9 生活工具（module_life / life 模块）

- AI 宝宝取名：按宝宝信息推测五行/星座偏好 → 生成候选名字（拼音/笔画/风格/寓意）→ 收藏管理；支持按姓名反推寓意，SSE 流式生成。

### FR-10 地理空间（module_geometry / geometry 模块）

- 地理要素（点/线/面，GeoJSON 进出）存入 PostGIS（WGS84，空间索引），提供全量/分页查询与 CRUD。
- 前端 Babylon.js 地球可视化绘制，支持自定义图层管理与内置底图图层。

### FR-11 任务队列（module_task / task 模块）

- 异步任务统一入口：创建/投递、列表/详情/状态统计、进度轮询、取消、重试、与 Celery 结果后端状态对账。
- 任务类型注册表（供前端下拉）；RAG 文档解析与重向量化等业务任务经此投递。

### FR-12 网页搜索（module_websearch / websearch 模块）

- 聚合多引擎搜索（DuckDuckGo 默认 / Tavily / Firecrawl），返回标题/链接/摘要/发布时间，支持时间范围与屏蔽站点，供 AI 问答联网检索。

### FR-13 自然语言（module_nlp / nlp 模块）

- 同义词组管理：建组/批量建组/整组替换/删除；单个与批量检索（同组同义词一并返回），供搜索扩词。

### FR-14 开发工具（module_dev_tools + module_template / 后台工具页）

- 模板字符串管理：`${variable}` 模板 CRUD、渲染（返回缺失变量）、语法校验。
- 脚手架模板：标准 CRUD 示例、文件上传/流式返回扩展示例、async/sync 并发行为教学端点。
- 接口测试页（前端 api-test 模块）：覆盖各模块端点的可视化用例。

### FR-15 前端平台能力

- 首页应用入口卡（按权限过滤）；后台工作台（状态卡 + 快捷入口 + 最近访问）。
- 全局登录/注册弹窗、账户设置页（资料/改密/外观/我的权限）。
- 后台侧边栏菜单（权限过滤）、面包屑、暗色主题（三态）、中/日/英基础国际化。
- 消息渲染：Markdown + LaTeX 公式 + Mermaid 图 + 表格 + 过程区块折叠；复制/导出 Word/PDF。
- 统一存储上传前端流程（哈希 → 直传/中转/秒传适配器）。

## 4. 非功能需求

| 类别 | 编号 | 需求 |
|------|------|------|
| 安全 | NFR-1 | 密码 argon2 哈希存储；JWT 双令牌；登出即吊销（Redis 黑名单 + refresh 落库置位） |
| 安全 | NFR-2 | 全接口 RBAC 鉴权（Casbin），未声明动作从严拒绝（fail-closed） |
| 安全 | NFR-3 | 个人数据按 user_id 隔离；项目内资源按成员档位校验 |
| 性能 | NFR-4 | AI 长对话 SSE 流式输出，检测客户端断连主动终止生成；LLM 请求超时 300s |
| 性能 | NFR-5 | 文档解析/向量化异步化（Celery），不阻塞接口；任务进度双写（DB + Celery） |
| 性能 | NFR-6 | 服务器状态接口 60s 缓存；系统状态响应带 X-Process-Time 耗时头；GZIP 压缩 |
| 可扩展 | NFR-7 | 后端模块自治（controller/service/dao/do/config/dependencies 分层），app.py 一行挂载；权限由模块声明、注册中心幂等同步 |
| 可扩展 | NFR-8 | 四类数据库（关系/缓存/向量/图）与文件存储均可通过配置切换实现 |
| 可移植 | NFR-9 | 开发态支持 SQLite + Fakeredis + LanceDB 零外部依赖运行；生产可切换 PostgreSQL + Redis + Milvus |
| 兼容 | NFR-10 | 前端支持桌面与移动端响应式（isMd/isLg 断点）；暗色模式 |
| 可维护 | NFR-11 | 统一日志体系（控制台 + 文件按日轮转）；统一异常处理（BizError/ValueError→400/兜底→500）；OpenAPI 文档 `/docs` |
| 测试 | NFR-12 | 后端 pytest（asyncio 自动模式）；前端 Playwright 三浏览器 E2E |

## 5. 运行环境需求

### 5.1 后端依赖

| 组件 | 开发默认 | 可切换（生产） | 用途 |
|------|----------|----------------|------|
| Python | ≥ 3.13（uv 管理） | — | 运行时 |
| 关系数据库 | PostgreSQL（或 SQLite） | SQLite/PostgreSQL | 业务表、Casbin 策略、LangGraph checkpointer |
| 缓存 | Fakeredis（本地持久化） | Redis | token 黑名单、Celery broker/backend |
| 向量库 | LanceDB（本地目录） | Milvus（含 BM25 稀疏向量） | 知识库分块向量 |
| 图数据库 | Neo4j | Neo4j | 知识图谱（预留） |
| 对象存储 | rustfs/S3（localhost:9000） | 任意 S3 协议/本地磁盘 | 统一文件存储 |
| AI 模型 | 按用户 model_config 配置 | OpenAI 兼容端点/Ollama/AWS Bedrock 等 | LLM/Embedding/Rerank/ASR/TTS |

### 5.2 前端依赖

- Node ≥ 22（pnpm 管理），Vite 开发服务器默认代理 `/base_server` → 后端 `http://0.0.0.0:2001`。

### 5.3 服务端口

| 服务 | 端口 |
|------|------|
| 后端 API（uvicorn） | 2001（config.yaml `server.port`） |
| 前端开发服务器 | 5173（VITE_PORT） |
| 对象存储（rustfs/S3） | 9000 |
