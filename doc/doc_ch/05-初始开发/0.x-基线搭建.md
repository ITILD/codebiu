# 0.x 初始开发（基线搭建期）

> 时间范围：2025-11-14 ~ 2026-06-30
> 本阶段为基线项目的初始开发期：从零搭建前后端基线，跑通通用能力（认证、文件、数据库、LLM 调用），为后续按版本迭代打基础。其他项目抄此基线时，从本阶段产物起步即可。

## 版本功能

### 基础设施（2025-11）
- 后端基线库项目结构（FastAPI + uv）、文档结构
- 前端基线：Vue3 项目框架、React 项目基础架构
- 登录注册、用户与模板模块、常用图标、Excel 处理
- OCR 前后端、CAD 相关能力
- pip 库模板 / 支持 `uv add` 的库模板、Nuitka 加密编译打包方案

### 数据与文件能力（2025-12 ~ 2026-02）
- 多数据库配置：PostgreSQL + LanceDB 向量库（替代 Milvus Lite）+ 图数据库（kuzu → graph_local → ladybug）
- 文件系统模块：预签名 URL 上传下载、文件内容去重、引用计数、本地/对象存储兼容
- AI 模块启用、模型配置示例、LLM 请求基础模板

### LLM 与业务模块（2026-03 ~ 2026-06）
- LLM SSE 事件流式响应、流式聊天（reactive 实时渲染）
- 同义词管理模块（批量分组查询、批量更新）
- `llm_tools` 模块（prompt 设计与外部工具调用）
- 3D 可视化（Babylon.js + MediaPipe 面部检测）
- 宝宝名字预测模块（baby_name）
- fastmcp 依赖集成（FastAPI + MCP）
