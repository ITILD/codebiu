# 打包构建

后端镜像、二进制编译与前端产物的构建方式汇总。
工具目录：`code/backend/server_py/tools/`

## 1. 后端 Docker 镜像

### 开发镜像(Dockerfile.dev,源码运行)

```bash
cd code/backend/server_py
bash tools/docker_dev/build.sh
# 等价于:
# docker build -f tools/docker_dev/Dockerfile.dev -t server_py:0.0.1 .
```

`build.sh` 内已包含"停旧容器 → 删旧容器 → 删旧镜像 → 重建"的完整流程，
修改 `PROJECT_VERSION` 即可滚动升版。

### 分发镜像(Dockerfile.dist,二进制运行)

配合 Nuitka 编译产物使用：

```bash
# 1. 先完成 Nuitka 编译(见下节)
# 2. 取消 Dockerfile.dist 中 COPY 注释,拷贝 dist_nuitka/app.dist
docker build -f tools/docker_build/Dockerfile.dist -t server_py:dist .
```

## 2. Nuitka 二进制编译(免源码分发)

> 适用于不希望交付 Python 源码的场景。

```bash
cd code/backend/server_py

# 按需编辑构建模块清单
# tools/nuitka_build/build_modules.py

# 执行编译(产物在 dist_nuitka/)
python tools/nuitka_build/build_modules.py
```

要点：

- 编译入口与模块在 `build_modules.py` / `module_loader.py` 中声明
- `app.py` 顶部保留了 `setup_module_path()` 调用注释，编译模式启用时取消注释
- 产物 `app.dist/` + `Dockerfile.dist` 组合成免源码镜像

## 3. 前端构建

```bash
cd code/frontend/vue3

pnpm i
pnpm run build          # 产物 dist/(含 type-check)

# 子路径部署时(如挂在 /app/ 下)调整 vite base 后重新构建
```

产物部署位置：`docker_compose/nginx/html/`

## 4. 文档 PPT 构建(可选)

```bash
cd doc/doc_ch/ppt
pnpm i
pnpm run build          # 产物 dist/,静态站点
```

## 5. 版本号约定

| 位置 | 说明 |
| :--- | :--- |
| `pyproject.toml` | 后端包版本 |
| `package.json` | 前端/PPT 版本 |
| `doc/tag_doc/tag_x.x.x.md` | 每个版本一份变更记录 |
| 镜像 tag | `server_py:<版本>` 与 tag_doc 对应 |
