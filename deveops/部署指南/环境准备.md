# 环境准备

生产/测试服务器的最低环境清单与初始化步骤。

## 1. 基础要求

| 项 | 最低要求 | 说明 |
| :--- | :--- | :--- |
| 系统 | Linux x64(推荐 Ubuntu 22.04 / Debian 12) | Windows Server 可用但脚本需 PowerShell 化 |
| CPU / 内存 | 2C4G(小规模) / 4C8G(含向量检索) | 知识库场景建议 4C8G 起 |
| 磁盘 | 40G+ | 数据库与文件存储单独挂盘更佳 |
| 端口 | 80/443(对外)、8600(后端)、15432(数据库,仅内网) | 15432 **不要**暴露公网 |

## 2. 安装 Docker 与 Compose 插件

```bash
# Ubuntu/Debian 官方脚本安装
curl -fsSL https://get.docker.com | bash

# 验证
docker --version
docker compose version

# (国内服务器)配置镜像加速
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<'EOF'
{
  "registry-mirrors": ["https://docker.m.daocloud.io"]
}
EOF
sudo systemctl restart docker
```

## 3. 数据库(容器方式,推荐)

部署编排已内置 `postgis/postgis:17-3.5`(自带 PostGIS 与 pgvector 能力)：

```bash
# 独立启动(不走 compose 时)
docker run -d --name pg \
  -e POSTGRES_DB=server_example \
  -e POSTGRES_USER=here \
  -e POSTGRES_PASSWORD=<强密码> \
  -p 15432:5432 \
  -v $HOME/pgdata:/var/lib/postgresql/data \
  --restart unless-stopped \
  postgis/postgis:17-3.5
```

## 4. 时区与系统参数

```bash
# 时区(容器内已在 compose 声明 TZ=Asia/Shanghai)
timedatectl set-timezone Asia/Shanghai

# 文件句柄数(大文件上传场景)
echo "fs.file-max = 65535" | sudo tee -a /etc/sysctl.conf
sudo sysctl -p
```

## 5. 应用配置文件

后端运行依赖 `config.yaml`(生产)与 `config.dev.yaml`(开发覆盖)：

```yaml
# 关键项示例
server:
  host: 0.0.0.0
  port: 8600
db:
  host: host.docker.internal   # 容器访问宿主机/同网络容器名
  port: 5432
  user: here
  password: <强密码>
  database: server_example
file_system:
  storage_type: local          # local / rustfs(S3兼容)
  max_size: 100                # 单文件上限(MB)
```

> 配置键与 `code/backend/server_py/config_template_full.yaml` 对齐，键名修改需同步后端 `StorageConfig` 等模型。
